# HTML Notes

A beginner-to-advanced guide to HTML, for anyone who wants to understand
how the web page they're reading actually works.

**Live site:** https://amina-m-e.github.io/html-blog/

## What's inside

- Structure basics: text nodes, comments, DOCTYPE, entities, elements
- How browsers read HTML, and why scripts can block a page
- Document metadata, semantic layout tags, forms, tables, and media
- Who else reads your HTML: search engines, bots, and screen readers
- Accessibility basics, global attributes, and a common-tags reference

## Built with

Plain HTML and CSS, with no frameworks and no JavaScript. Hosted on GitHub Pages.

## Run it locally

Open the folder in VS Code and use the Live Server extension on `index.html`.
